## 1. 背景と目的

### 1.1 現状の問題

現行 DiffXL は比較エンジン（`.xlsx` OOXML 抽出＋OpenCV）と、**Excel COM 埋め込みビュー**を併用している。  
要件上「Excel そのまま 1px 再現」が最優先だったが、実運用では次の問題が大きい。

- 埋め込み Excel の挙動が不安定・重い
- 比較したいのは**見た目の再現ではなく中身の差分**
- 座標同期・行高列幅一致などにコストがかかり、価値が低い

### 1.2 目的

2 つの `.xlsx` の**内容**を比較し、「どこがどう違うか」を安定・高速に示す。  
Excel のインストールおよび埋め込み表示には**依存しない**。

### 1.3 成功基準

- Excel 未インストールでも比較・閲覧できる
- セル位置が違っても中身が同じなら差分に出ない
- 画像の位置・パスが違っても見た目が同じなら差分に出ない
- 画像列の途中挿入（8 枚 vs 9 枚）でも後ろが正しく再同期される
- テーブルで行削除（12345 vs 1245）が「3 が無い」と一目で分かる
- 画像の部分差は該当領域だけ赤枠＋黄半透明で分かり、ON/OFF できる
- シートは同名自動対応に加え、異名の手動対応・片側のみシートに対応する

## 2. 方針決定（合意事項）

| 項目 | 決定 |
|------|------|
| 比較の中核 | **部品分解した意味モデル**同士の比較（HTML/Markdown 比較は本体にしない） |
| 表示 | **自前内容ビューのみ**。Excel 埋め込みは**完全廃止** |
| セル | 位置無視。値＋背景色の内容比較 |
| 画像・図形 | シート座標無視。**出現順の系列アラインメント**＋見た目比較 |
| テーブル | ボーダーからブロック検出。内部は**行の系列 diff** |
| 書式 | フォント・罫線スタイル差分は対象外（border は表検出にのみ使用） |
| 行高・列幅 | 無視 |
| MiniMap | **現在シートのみ**（全シート横断は廃止） |
| HTML/MD | 将来のエクスポート候補。比較エンジンには使わない |

### 2.1 採用しなかった案

| 案 | 不採用理由 |
|----|------------|
| HTML 変換して比較 | 構造同期・画像スキップが弱く、差分がノイズになりやすい |
| Markdown 変換して比較 | 画像・背景色・部分ハイライトを扱えない |
| Excel ハイブリッド継続 | 安定性・依存・価値の問題が残る |

## 3. 比較モデル（§1）

### 3.1 パイプライン

```
.xlsx → ContentExtractor（OOXML のみ）
      → WorkbookContent / SheetContent
      → DiffEngine（部品ごと比較）
      → DiffResult + 左右 Content
      → Content View（WPF）
```

### 3.2 原則：位置は比較キーにしない

| 例 | 判定 |
|----|------|
| 左 A1=`Hello` / 右 A2=`Hello` | 差分なし |
| 同一見た目の画像が左 B20・右 C25（パス相違） | 差分なし |
| 左 `Hello`,`World` / 右 `World`,`Hello` | 差分なし（セルは多重集合） |
| 左に `Hello`×2 / 右に `Hello`×1 | 個数差 1 |

セル番地・画像アンカー・パッケージパスは **UI 参考メタデータ** として保持するのみ。

### 3.3 トークン種別

#### セルトークン（テーブル外）

- キー: `(Text, BackgroundColor)` の多重集合
- 空セルはトークン化しない
- 数式はキャッシュ表示値（`<v>`）優先
- 背景なしは `null`

#### テーブルブロック

- border 有無から連結した一覧領域
- シート内の**出現順**で左右テーブルを系列アラインメント（途中スキップ可）
- 内部は**行シーケンス**として LCS／編集距離で比較（下記 3.5）

#### 画像トークン

- **出現順**のシーケンス（reading order: 行→列で安定ソート）
- 一致は見た目類似（位置コストなし）
- DP で Match / SkipLeft / SkipRight

#### 図形トークン

- 画像に準拠（順序＋内容。内テキスト＋ラスタ等）

### 3.4 画像の系列アラインメント（必須ケース）

左 8 枚・右 9 枚で、右の 5 枚目だけ余分、以降がほぼ一致する場合:

```
L1-L4 ↔ R1-R4
R5        → ImageOnlyRight
L5-L8 ↔ R6-R9
```

動的計画法で類似度行列に基づき最適対応を求める。無理な低類似 Match は禁止または高コスト。

### 3.5 画像の見た目比較（スクショ想定）

人が 2 回キャプチャする前提:

1. 前処理（縮小・ノイズ低減）
2. グローバル位置合わせ（ずれ吸収）
3. 差分マップ
4. 微小領域の除去（面積閾値）
5. 有意領域のみハイライト用矩形リスト化
6. 有意領域が無ければ同一（Diff なし）

無視: 全体の数 px ずれ、圧縮ノイズ、薄いにじみ。  
拾う: テキスト差し替えなど、ある程度の面積を持つ差。

### 3.6 テーブル行比較（必須ケース）

左行: 1,2,3,4,5 ／ 右行: 1,2,4,5

- 行 3 が **Delete（左のみ）** と明示
- 4,5 は再対応
- 行内の一部セル Text 変更は、対応行内のセル差分として強調
- 行の追加は **Insert（右のみ）**

行キーは行内セル Text（および背景色）のタプル。同内容行が複数ある場合は出現順で安定マッチ。

### 3.7 シート対応

| モード | 仕様 |
|--------|------|
| 既定 | **同名シート**同士を自動ペア |
| 片側のみ | 多い側のシートは Structure 差分。内容は片側表示 |
| 手動 | 同名同期を解除し、左右で**別シート名**を選んで比較可能 |

### 3.8 DiffKind（論理）

| Kind | 意味 |
|------|------|
| Text | セル値の差・片側のみ値 |
| Background | 背景色の差 |
| TableRowDelete | テーブル行が左のみ |
| TableRowInsert | テーブル行が右のみ |
| TableCellChange | 対応行内のセル変更 |
| Image | 対応画像の部分差 |
| ImageOnlyLeft / ImageOnlyRight | 片側のみ画像 |
| Shape / ShapeOnly* | 図形 |
| Structure | シート有無など |

同一セルで値と背景が両方違う場合、エンジン上は分離してよい。

### 3.9 抽出しないもの

- フォント等の文字書式
- 罫線のスタイル差分（検出用途の border 有無のみ）
- 行高・列幅
- 印刷設定・VBA・ピボット内部等
- `.xls` / `.xlsm`

## 4. 表示 UI（§2）

### 4.1 画面

| ID | 役割 |
|----|------|
| SCR-01 | 起動・左右 `.xlsx` 選択 |
| SCR-02 | メイン比較（内容ビュー） |
| SCR-03 | シート対応付け（同名／手動／片側） |
| SCR-05 | 設定 |
| SCR-06 | 片側ファイル差し替え |

- Excel 利用可否チェックは廃止
- セル位置アンカー UI は初期スコープ外（位置無視方針と矛盾するため）

### 4.2 メインレイアウト

- 左右: ファイル名・シートコンボ・内容ビュー（タブ）
- 右端: **MiniMap（現在シートの差分のみ）**
- 下部: 差分リスト（既定は現在シート）
- ツールバー: 再比較、**ハイライト ON/OFF**、シート対応、設定、戻る

### 4.3 内容タブ

| タブ | 内容 |
|------|------|
| セル | テーブル外トークン等 |
| テーブル | 一覧グリッド。行追加・削除・セル変更が視覚的 |
| 画像 | アラインメント後のペア行。片側のみ行を含む |
| 図形 | 画像と同様 |

Excel そっくりのグリッド再現はしない。行高・列幅は無視。

### 4.4 MiniMap

- **全シート横断表示はしない**
- シート変更時に、そのシート用 MiniMap に差し替え
- クリックでそのシート内の差分へ移動

### 4.5 画像ハイライト見た目

有意差分領域ごとに:

| 属性 | 既定値 |
|------|--------|
| 枠 | 赤・**3px** |
| 塗り | 黄・**不透明度 50%** |

- ツールバーで一括表示／非表示（データ保持、再比較不要）
- 色・枠幅・α は設定変更可

### 4.6 テーブル UI

- 左右に整列した一覧
- Delete 行: 左あり右なし（削除と分かる色）
- Insert 行: 右あり左なし（追加と分かる色）
- 変更セル: 値の差をハイライト
- 元アドレスはツールチップ程度

### 4.7 ナビゲーション

- Excel 座標の同期スクロールはしない
- 差分選択・ペア行・テーブル対応行の**選択同期**
- 次の差分／前の差分（現在シート内）

### 4.8 シート操作 UI

- 既定: 同名ペア
- 左右シートを独立選択し、異名同士を比較可能
- 片側のみシート選択時は片側表示＋Structure

## 5. アーキテクチャと移行（§3）

### 5.1 層構造

```
VIEW (WPF, no Excel)
  ← WorkbookContent + DiffResult
LOGIC/Diff (Extractor, Aligners, Comparators, DiffEngine)
  ← OOXML
XlsxPackageReader
```

### 5.2 主要コンポーネント

| 名前 | 責務 |
|------|------|
| XlsxPackageReader | Text, Bg, border, images, shapes |
| TableDetector | border → TableBlock |
| SheetMatcher | 同名／手動／片側 |
| CellBagComparer | テーブル外セル |
| TableSequenceAligner | テーブル間の順序対応 |
| TableRowAligner | 行 LCS（追加・削除・変更） |
| ImageSequenceAligner | 画像 DP |
| ImageVisualComparer | 位置合わせ＋領域矩形 |
| Shape* | 図形（画像準拠） |
| DiffEngine | 統括 |
| ContentPane / TableDiffGrid / ImagePairView | UI |
| MiniMapControl | 現在シートのみに縮小 |

### 5.3 削除対象

- `LOGIC/Excel/*`（COM、同期スクロール、埋め込み）
- `ExcelHostControl` 等の埋め込み UI
- Excel 必須の起動チェック
- 全シート横断 MiniMap ロジック
- 内容同期のための Excel 行座標マップ（リスト索引ベースへ置換）

### 5.4 維持・拡張

- OpenCV による画像差分の核
- キャッシュ（`%AppData%\Roaming\DiffXL\cache`）
- 設定 YAML、ログ、x64 単一 exe 方針
- SheetMatcher / DiffEngine の骨格

### 5.5 移行フェーズ

| フェーズ | 内容 |
|----------|------|
| M1 | モデル拡張（位置非キー、Bg、Table、Shape、HighlightRegion） |
| M2 | 抽出（背景・border・表・図形） |
| M3 | 比較（bag、行 LCS、画像 DP、片側シート）スモーク |
| M4 | Content UI 骨格、Excel ホスト切断 |
| M5 | 差分リスト・表グリッド・画像ハイライト ON/OFF |
| M6 | MiniMap 現在シート、手動シート対応、COM 削除掃除 |
| M7 | サンプル・要件定義・ロードマップの方針更新 |

## 6. エラー処理・設定（§4）

### 6.1 エラー

| 状況 | 扱い |
|------|------|
| 拡張子が `.xlsx` 以外 | 受け付けずメッセージ |
| 破損・暗号化・読取失敗 | エラー表示、部分結果があれば明示 |
| 画像デコード失敗 | 当該画像をスキップし警告ログ、他は継続 |
| メモリ・巨大ファイル | 進捗表示、可能なら縮小比較、失敗時は分かりやすいメッセージ |

Excel 起動失敗メッセージは出さない。

### 6.2 設定既定値（YAML）

| キー（論理名） | 既定 |
|----------------|------|
| 画像ハイライト枠 | 赤、3px |
| 画像ハイライト塗り | 黄、α 0.5 |
| ハイライト初期表示 | ON |
| 画像同一判定閾値 | 実装時キャリブレーション後に固定既定 |
| 最小有意差分面積 | 同上 |
| 差分リスト既定フィルタ | 現在シート |

## 7. テスト方針（§5）

### 7.1 必須シナリオ

1. セル位置無視: A1 Hello vs A2 Hello → 差なし  
2. 背景色のみ差 → Background  
3. テーブル行: 12345 vs 1245 → 3 が Delete  
4. テーブル内 1 セル文言変更 → そのセルのみ Change  
5. 画像: 同見た目・異位置 → 差なし  
6. 画像: 8 vs 9、4 の次が余分 → OnlyRight 1 件、以降再同期  
7. 画像: 部分テキスト差 → 領域に赤 3px＋黄 50%。OFF で非表示  
8. シート: 同名、片側のみ、異名手動ペア  

### 7.2 回帰

- Excel COM 前提の UI 自動テストは内容 UI 向けに置換
- エンジンは exe スモーク（既存 `_smoke` 方針を拡張）で担保

## 8. 非目標（初期スコープ外）

- HTML/Markdown を主比較経路にすること
- フォント・罫線スタイル・配置の差分
- 行高・列幅の再現
- `.xls` / `.xlsm`
- 手動「この範囲は表」指定（border 検出失敗時はバラセルへフォールバック）
- セル文字列のあいまい一致（Hello vs Hello! は別トークン）
- Excel での編集・マージ結果の書き戻し

## 9. 要件定義との関係

本書は要件定義 0.4 の **「Excel 本体描画が最重要」** を、次の方針に置き換える。

- 最重要品質: **内容差分の正確さ・分かりやすさ・安定性**
- ビュー: 自前内容ビュー（WinMerge 的操作感は維持）

実装着手前に `10_管理資料/要件定義.md` およびロードマップ（計画 02 等）を本書に合わせて改訂する（移行フェーズ M7）。
