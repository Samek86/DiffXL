# DiffXL

2 つの Excel ファイル（`.xlsx`）を比較し、差分を分かりやすく表示する Windows デスクトップアプリです。

## 前提条件

| 項目 | 内容 |
|------|------|
| OS | Windows 64bit |
| .NET | .NET Framework 4.8 以降 |
| Excel | Microsoft Excel（デスクトップ版）がインストールされていること |
| 対象ファイル | **`.xlsx` のみ** |

## 同梱ファイル

| ファイル | 説明 |
|----------|------|
| `DiffXL.exe` | 本体（マネージ依存は内包） |
| `DiffXL.exe.config` | .NET ランタイム用設定（アプリ設定ではない） |
| `README.md` | 本ファイル |

ユーザー設定・ログ・キャッシュは exe 横ではなく、次の場所に保存されます。

```
%AppData%\Roaming\DiffXL\
  settings.yaml
  logs\
  cache\
  native\
```

## 使い方

1. `DiffXL.exe` を起動する  
2. 左右の `.xlsx` を選択して **比較開始**  
3. 差分は半透明の黄色（既定・不透明度 50%）で強調される  
4. **差分強調 ON/OFF**（または `Ctrl+H`）で強調表示だけ切り替えられる（再比較不要）  
5. **MiniMap** のクリックで差分位置へジャンプ  
6. **シート対応** / **アンカー** / **片側差し替え** / **再比較** で比較条件を調整  
7. **設定** で差分色・不透明度・同期スクロールを変更（YAML に保存）  
8. **最初から** でファイルを閉じて起動画面に戻る  

## 注意

- 表示の完全再現は Excel 本体の埋め込み表示に依存します。  
- OpenCV による画像差分は、初回以降 `%AppData%\Roaming\DiffXL\native` 等を利用します。  
- 第三者ライブラリのライセンスはリポジトリの `30_参考資料/licenses/` を参照してください。
