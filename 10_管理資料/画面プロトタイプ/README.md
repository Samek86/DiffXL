# DiffXL 画面プロトタイプ

要件定義（`10_管理資料/要件定義.md`）に基づく、**画面レイアウト・遷移確認用**の HTML プロトタイプです。

実際の Excel 読み込み・OpenCV 比較・YAML 永続化は行いません。見た目と操作フローの確認が目的です。

## 開き方

1. `index.html` をブラウザで開く（ダブルクリック、またはブラウザへドラッグ）
2. 推奨: Chrome / Edge の最新版

ローカルサーバーは不要です（相対パスの CSS/JS のみ）。

## 含まれる画面

| ID | 画面 | プロトタイプ上の操作 |
|----|------|----------------------|
| SCR-01 | 起動／ファイル選択 | 左右「ファイルを選択」→「比較開始」、または「デモで開く」 |
| SCR-02 | メイン比較 | 左右 Excel モック、差分色、同期スクロール、MiniMap |
| SCR-03 | シート対応付け | ツールバー「シート対応」 |
| SCR-04 | アンカー設定 | ツールバー「アンカー」 |
| SCR-05 | 設定 | ツールバー「設定」（YAML 保存はトーストのみ） |
| SCR-06 | 片側差し替え | 各ペインの「差替」 |

## 試してほしいこと

1. **デモで開く** → メイン比較画面へ遷移
2. 左右ビューをスクロール → **同期スクロール**
3. **MiniMap** をクリック／ドラッグ → 本体が移動
4. **シート対応** / **アンカー** → ダイアログ → 再比較シミュレーション
5. **設定** → 左ナビでカテゴリ切替 → 「YAML に保存」
6. **差替** → 片側パス変更 → 再比較

## 差分表示の色（案）

| 種別 | 色 |
|------|-----|
| テキスト差分 | 赤系背景 |
| 画像差分 | 黄色オーバーレイ |
| 片側のみの画像 | 緑の破線／薄表示 |
