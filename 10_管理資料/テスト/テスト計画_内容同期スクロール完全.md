# テスト計画: 内容同期スクロール完全（画像対応含む）

**対象:** DiffXL 内容ベース縦スクロール同期 + 画像最適対応  
**サンプル:** `30_参考資料/samples/content_scroll_*.xlsx` + `content_scroll_expected.json`  
**自動化:** `10_管理資料/テスト/run-content-scroll-test.ps1`

---

## 三段ハーネス概要

| 段 | 名前 | COM | 入力 | 合否 |
|----|------|-----|------|------|
| T1 | Map/Match 単体（expected 駆動） | 不要 | content_scroll xlsx + expected.json | `PERFECT_SCROLL_PASS` |
| T2 | DiffEngine 統合（画像 kind） | 不要 | 同上（PerfectSmoke 内） | imagePairs / leftOnly / rightOnly |
| T3 | Excel ライブ | 必要 | DiffXL.exe `--auto-live-test` | `AUTO_LIVE_PASS` / `FAILURES=0` |

---

## T1 / T2 — ContentScrollPerfectSmoke

### 実行

```powershell
cd 20_ソース\DiffXL\DiffXL\bin\x64\Debug
# ビルド後 csc:
# csc /platform:x64 /r:DiffXL.exe /out:ContentScrollPerfectSmoke.exe ..\..\..\..\_smoke\ContentScrollPerfectSmoke.cs
.\ContentScrollPerfectSmoke.exe `
  --left   ..\..\..\..\..\30_参考資料\samples\content_scroll_left.xlsx `
  --right  ..\..\..\..\..\30_参考資料\samples\content_scroll_right.xlsx `
  --expected ..\..\..\..\..\30_参考資料\samples\content_scroll_expected.json
```

### 検証内容

1. `DiffEngine.Compare(left, right)` 成功、`Alignments.Count >= 4`
2. 各シートの `ScrollMap` で `scrollSamples` を検証
   - `from=L` → `MapLeftToRight(row)`
   - `from=R` → `MapRightToLeft(row)`
   - `expectOther` 完全一致 / `expectOtherMax` 以下
3. `imagePairs` の `leftRowStart` / `rightRowStart` が `Alignments.Images` と一致
   - `kind=exact` → `IsExactHashMatch`
   - `kind=modified` → ペアかつ非 exact
4. `leftOnly` / `rightOnly` の RowStart 一致

### 主要 expected（SC_画像ギャップ）

| 種別 | 期待 |
|------|------|
| imagePairs | L5↔R5 exact, L8↔R12 exact |
| rightOnly | R8 |
| scroll | L5→5, R9≤7, L8→12, R12→8 |

### 合否

- 標準出力末尾: `PERFECT_SCROLL_PASS` / 終了コード 0
- 失敗時: `PERFECT_SCROLL_FAIL` / 終了コード 1

## T3 — Excel ライブ（auto-live）

### 実行

```powershell
$root = "C:\JUN\WORK\DiffXL"
& "$root\20_ソース\DiffXL\DiffXL\bin\x64\Debug\DiffXL.exe" `
  --auto-live-test `
  --left  "$root\30_参考資料\samples\content_scroll_left.xlsx" `
  --right "$root\30_参考資料\samples\content_scroll_right.xlsx" `
  --report "$root\10_管理資料\テスト\_latest_content_scroll_perfect.txt"
```

### 自動検証項目（content_scroll 分岐）

パスに `content_scroll` を含む場合、`VerifyContentScrollPerfectLiveAsync` が動作する。

1. 比較成功、`Alignments.Count >= 4`
2. シート `SC_画像ギャップ` を選択
3. マップ点: L5→5, R9≤7, L8→12, R12→8
4. 画像対応: L5↔R5 exact, L8↔R12 exact, rightOnly R8
5. 右を only 画像 RowStart=8 へ `TrySetScroll` → 左実測 `<= 7`（±2 で右位置）
6. 右を same_B (row 12) へ → 左 8 / 右 12（各 ±2）
7. 横: `SC_横同期` で左 col=5 → 右 col=5
8. レポートに `CONTENT_SCROLL_PERFECT_OK` と `FAILURES=0` / `AUTO_LIVE_PASS`

### full_feature 回帰

パスに `content_scroll` を含まない場合は従来どおり 製品カタログ / ずれ試験 / 長い一覧 を検証（`CONTENT_SCROLL_OK`）。
