# 06 リリース配布・検証 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release|x64 で原則 `DiffXL.exe` のみの配布物を作り、要件どおりの前提条件・AppData・差分 UX・Excel 表示を検証チェックリストで担保して `40_リリース` に配置する。

**Architecture:** Costura でマネージ埋め込み、OpenCV native は初回起動で AppData 展開。リリースフォルダには exe と短い README のみ。検証は機能・非機能・失敗系の固定リストで行う。

**Tech Stack:** MSBuild Release|x64、Costura.Fody、計画 01–05 の成果物

## Global Constraints

- 配布単位: **`DiffXL.exe` のみ**（README は可）
- x64、`.xlsx` のみ、Excel 必須（全バージョン対象）
- AppData: `%AppData%\Roaming\DiffXL`
- 差分既定: 黄・50%、トグル可
- OSS ライセンス表記をリポジトリ内に残す

**Depends on:** 計画 01–05 完了（または最低限の垂直スライス完了後のプレリリース）
