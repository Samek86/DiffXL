# 04 差分オーバーレイ・色・表示切替 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 比較結果を Excel ビュー上に半透明の差分色で重ね、既定の黄色 50% 透明度を設定可能にし、ツールバーのトグルで差分強調の表示／非表示を即時切り替えられるようにする。

**Architecture:** `DiffOverlayLayer`（WPF Canvas）を各 `WorkbookPane` の前面に載せ、`DiffHighlightController` が `DiffResult` と `AppSettings.Diff` からブラシを生成する。表示フラグは UI 状態として保持し、OFF でも `DiffResult` は破棄しない。

**Tech Stack:** WPF、`SolidColorBrush`（Alpha）、計画 02 の ViewMetrics、計画 03 の DiffResult

## Global Constraints

- 既定色: **黄色 `#FFFF00`、不透明度 0.5**
- 設定で色・不透明度を変更でき YAML 保存
- **表示／非表示トグル**必須。OFF でも再比較不要
- 1px ビュー本体は Excel。オーバーレイは補助（位置ずれは可能な限り最小化）
- 日本語コメント、AppData 設定、x64

**Depends on:** 計画 01（設定）、02（ホスト）、03（DiffResult）

### Task 1: DiffHighlightStyle（色計算）

**Files:**
- Create: `LOGIC/Diff/DiffHighlightStyle.cs`

**Interfaces:**
- Consumes: `AppSettings.Current.Diff.HighlightColor`, `HighlightOpacity`
- Produces: `Color ToColor()`, `Brush CreateBrush()`, `static DiffHighlightStyle FromSettings()`

- [x] **Step 1: 実装**

```csharp
/// <summary>
/// 差分強調の色と不透明度を表す。
/// </summary>
public sealed class DiffHighlightStyle
{
    public byte R { get; set; } = 255;
    public byte G { get; set; } = 255;
    public byte B { get; set; } = 0;
    /// <summary>0.0〜1.0。既定 0.5。</summary>
    public double Opacity { get; set; } = 0.5;

    public static DiffHighlightStyle FromSettings()
    {
        var d = AppSettings.Current.Diff;
        var s = new DiffHighlightStyle { Opacity = d.HighlightOpacity };
        ParseHexRgbColor(d.HighlightColor, out var r, out var g, out var b);
        s.R = r; s.G = g; s.B = b;
        return s;
    }

    public Color ToWpfColor()
    {
        var a = (byte)Math.Max(0, Math.Min(255, (int)Math.Round(Opacity * 255)));
        return Color.FromArgb(a, R, G, B);
    }

    public SolidColorBrush CreateBrush()
    {
        var brush = new SolidColorBrush(ToWpfColor());
        brush.Freeze();
        return brush;
    }

    // ParseHexRgbColor: "#RRGGBB" / "#AARRGGBB" / "RRGGBB"
}
```

- [x] **Step 3: Commit**

